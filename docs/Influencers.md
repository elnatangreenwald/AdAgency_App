# משפיענים

מאגר משפיענים שאפשר להציע ללקוחות. המאגר נבנה בבסיסו מהמסמך `influencers-consolidated.docx` (44 שמות משלוש רשימות, ריכוז מ-14 באוקטובר 2026), ואפשר להוסיף ולעדכן משפיענים ידנית.

## מי יכול מה

| פעולה | הרשאה |
|---|---|
| צפייה, חיפוש, סינון | כל משתמש מחובר |
| הוספה ועריכה | כל משתמש מחובר |
| מחיקה | מנהל או אדמין |

ההרשאה לדף עצמו ב-`permissions_db.json` היא `עובד`. חסימת המחיקה נאכפת בשרת (`is_manager_or_admin`), וכפתור המחיקה מוסתר בממשק למי שאין לו הרשאה.

## נתיבים

| נתיב | תיאור |
|---|---|
| `/app/influencers` | עמוד המשפיענים |
| `GET /api/influencers` | רשימת המשפיענים + רשימת הקטגוריות (`groups`) |
| `POST /api/influencers` | הוספת משפיען |
| `POST /api/influencers/<id>` | עדכון משפיען (רק השדות שנשלחו מתעדכנים) |
| `POST /api/influencers/<id>/delete` | מחיקה — מנהל/אדמין |

## מודל רשומה

```json
{
  "id": "uuid",
  "name": "שם (חובה)",
  "instagram": "handle בלי @",
  "followers": "טקסט חופשי, למשל: כ־57.6 אלף",
  "followers_count": 57600,
  "topics": "אופי התוכן",
  "notes": "הערות",
  "age": "גיל (טקסט, למשל 28–29)",
  "group": "רשימה / קטגוריה",
  "source_url": "קישור למקור הנתונים",
  "contact": "איש קשר / טלפון",
  "price": "מחיר",
  "needs_verification": true,
  "created_at": "iso",
  "updated_at": "iso",
  "updated_by": "user_id"
}
```

- `instagram` — אפשר להזין `@handle` או קישור מלא לפרופיל; השרת שומר רק את ה-handle.
- `followers_count` — מחושב בשרת מתוך `followers` ומשמש למיון. מבין "אלף", "מיליון", `K`, `M` ומספרים עם פסיקים. אם אין מספר, הערך `null`.
- `needs_verification` — דגל "טעון אימות". בייבוא הראשוני סומנו כך רשומות שבמסמך המקור היה בהן "לא אומת", "טעון אימות" או "לא אותר", או שחסר בהן handle או מספר עוקבים.

## אחסון

- **פיתוח (JSON):** `influencers_db.json`.
- **פרודקשן (PostgreSQL):** טבלה `influencers` עם `id` + `data` (JSONB). הטבלה נוצרת בשימוש הראשון, ואם היא ריקה מיובא אליה התוכן של `influencers_db.json` (שנשמר בגיט כ-seed).

## ממשק

- קישור בסרגל הצד: **משפיענים**.
- סינון לפי רשימה/קטגוריה וסטטוס אימות, חיפוש חופשי, מיון לפי עוקבים או שם.
- כרטיס לכל משפיען: קישור לאינסטגרם, עוקבים, תוכן, גיל, מחיר, איש קשר, הערות וקישור למקור.
- **הצעה ללקוח:** מסמנים משפיענים בתיבת הסימון, ובפס שמופיע לוחצים "העתקה לשליחה ללקוח". מועתק ללוח טקסט עם שם, אינסטגרם, עוקבים ואופי התוכן של כל משפיען, מוכן להדבקה במייל או בוואטסאפ.

## הערה על הנתונים

מספרי העוקבים במאגר הראשוני הם נתונים שפורסמו או הערכות מאתרים חיצוניים, לא ספירה חיה. ההערות על זיהוי מגזרי הועתקו מהמסמך ואינן אימות של התאמה.
