# מצב לימודי (Learning Mode) – סיורים מודרכים במערכת

## מה זה
כפתור צף ובולט **"מצב לימודי"** (בפינה השמאלית התחתונה, ליד כפתור הצ'אט). כשמפעילים אותו:

1. **סיור היכרות כללי** (פעם אחת): התפריט, מדידת הזמן, ההתראות, הצ'אט והכפתור עצמו.
2. **סיור קצר לכל מסך** – בכניסה הראשונה לכל מסך המסך מוחשך, האלמנט הרלוונטי מודגש במסגרת זהב ובועת הסבר מצביעה עליו (3–7 צעדים, חצי דקה).
3. **סימני ? צהובים** – אחרי הסיור הם נשארים על האלמנטים החשובים במסך. מעבר עכבר / לחיצה מציגים הסבר קצר. הם נעלמים אוטומטית כשנפתח חלון (Dialog) מעליהם.

מהכפתור (כשהמצב פעיל) אפשר: להפעיל שוב את סיור המסך הנוכחי, להפעיל את הסיור הכללי, להציג/להסתיר את סימני ה-?, לאפס את כל הסיורים, ולכבות את המצב.

ניווט בסיור: כפתורי הבא/הקודם, חיצי מקלדת (← קדימה, → אחורה), Enter, ו-Esc לסגירה.

המצב נשמר ב-`localStorage` לכל משתמש/דפדפן:
- `learningMode.enabled` – האם המצב פעיל
- `learningMode.seenTours` – אילו סיורים כבר הוצגו
- `learningMode.hotspots` – האם להציג סימני ?

## מבנה הקוד
`src/components/learning/`

| קובץ | תפקיד |
|---|---|
| `index.ts` | ייצוא + הדגל `LEARNING_MODE_AVAILABLE` |
| `LearningModeContext.tsx` | ניהול מצב: הפעלה, סיור פעיל, תור סיורים, מה נצפה, התאמת סיור לנתיב |
| `tours.ts` | **כל התוכן**: `GENERAL_TOUR` ו-`PAGE_TOURS` (סיור לכל נתיב) |
| `TourOverlay.tsx` | ההחשכה, מסגרת ההדגשה והבועה (מיקום אוטומטי, מעקב אחרי גלילה/שינוי גודל) |
| `Hotspots.tsx` | סימני ה-? והבועות הקטנות |
| `LearningModeButton.tsx` | הכפתור הצף והתפריט שלו |
| `dom.ts` | איתור אלמנטים, בדיקת נראות/כיסוי, המתנה לטעינה |

החיבור נעשה ב-`src/components/layout/Layout.tsx` (רק באזור המחובר של המערכת). העיצוב (אנימציות, הצללה) ב-`src/index.css` תחת `Learning mode`.

## איך זה מוצא את הכפתורים
כל אלמנט שמוסבר מסומן בקוד במאפיין `data-tour="<id>"`, למשל:

```tsx
<Button data-tour="tasks-new-task" onClick={...}>משימה מהירה</Button>
```

ובקובץ `tours.ts`:

```ts
{ target: 'tasks-new-task', title: 'משימה מהירה', body: 'פותח חלון להוספת משימה...' }
```

- צעד בלי `target` מוצג כבועה במרכז המסך (מתאים להקדמה).
- צעד שהאלמנט שלו לא קיים כרגע (אין נתונים, אין הרשאה, תצוגה אחרת, מובייל) **מדולג אוטומטית** – לכן מותר לתאר אלמנטים אופציונליים.
- אם יש כמה אלמנטים עם אותו `data-tour`, נבחר הראשון שנראה על המסך.
- לפני תחילת סיור המערכת ממתינה עד ~3.5 שניות שהנתונים ייטענו.

## הוספת / עריכת סיור
1. הוסיפו `data-tour="screen-thing"` לאלמנט (רק מאפיין, בלי שינוי התנהגות). לרכיבים מותאמים ודאו שהם מעבירים props ל-DOM (כמו `Button`/`Card` של shadcn).
2. הוסיפו צעד ב-`PAGE_TOURS` בקובץ `tours.ts`. למסך חדש – אובייקט חדש עם `id` ייחודי ו-`paths` בתבנית react-router (למשל `'/client/:clientId'`).
3. אופציונלי: `placement` (`top`/`bottom`/`left`/`right`) ו-`tip` (טיפ בתיבה צהובה).

שינוי `id` של סיור יגרום לו להופיע שוב לכל המשתמשים.

## הסרה (הכפתור זמני)
ב-`src/components/learning/index.ts`:

```ts
export const LEARNING_MODE_AVAILABLE = false;
```

זה מסתיר את הכפתור ואת כל ממשק הסיורים. מאפייני ה-`data-tour` בדפים לא משפיעים על כלום ואפשר להשאיר אותם.
