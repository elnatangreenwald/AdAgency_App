# סיסמאות רשתות

עמוד לריכוז יוזרים וסיסמאות של רשתות חברתיות ושירותים נלווים.
הקישור מופיע בתפריט **לכל המשתמשים**. הצפייה בסיסמאות עצמן נשארת **לאדמין בלבד**.

- **אדמין** רואה את כל הרשומות, יכול לחפש / לערוך / למחוק ולהוסיף.
- **שאר המשתמשים** רואים רק טופס הוספה: לקוח, פלטפורמה, שם משתמש, סיסמה. אחרי השליחה הרשומה מגיעה לריכוז של האדמין, בלי לחשוף סיסמאות קיימות.

## נתיבים

| נתיב | תיאור | הרשאה |
|---|---|---|
| `/app/admin/passwords` | עמוד הסיסמאות | כל משתמש מחובר |
| `GET /api/admin/network_passwords` | רשימת רשומות | אדמין בלבד |
| `POST /api/admin/network_passwords` | הוספת רשומה | כל משתמש מחובר |
| `POST /api/admin/network_passwords/<id>` | עדכון רשומה | אדמין בלבד |
| `POST /api/admin/network_passwords/<id>/delete` | מחיקת רשומה | אדמין בלבד |

## מודל רשומה

```json
{
  "id": "uuid",
  "client": "שם לקוח / חשבון",
  "platform": "אינסטגרם | טיקטוק | ...",
  "username": "יוזר או מייל",
  "password": "סיסמה",
  "url": "קישור אופציונלי",
  "notes": "הערות",
  "created_at": "iso",
  "updated_at": "iso",
  "updated_by": "user_id"
}
```

## אחסון

- **פיתוח (JSON):** `network_passwords.json`
- **פרודקשן (PostgreSQL):** טבלה `network_passwords` עם `id` + `data` (JSONB). הטבלה נוצרת בעצלתיים בשימוש הראשון, ואם היא ריקה מיובא ה-seed מקובץ ה-JSON.

## ממשק

- קישור בסרגל הצד: **סיסמאות רשתות** (גלוי לכולם)
- אדמין: חיפוש, סינון, כרטיסים מקובצים לפי לקוח, הצגה/העתקה, עריכה ומחיקה
- עובד: טופס הוספה בלבד (לקוח, פלטפורמה, שם משתמש, סיסמה)

## אבטחה

הצפייה נאכפת **בשרת** (`is_strict_admin`) ב-GET / עדכון / מחיקה. משתמש שאינו אדמין מקבל `403` אם ינסה למשוך את הרשימה.
ההרשאה לדף עצמו ב-`permissions_db.json` היא `עובד`.

אין להפיץ את קובץ `network_passwords.json` מחוץ למערכת.
