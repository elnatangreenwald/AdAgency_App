# סיסמאות רשתות — עמוד אדמין

עמוד נפרד לריכוז יוזרים וסיסמאות של רשתות חברתיות ושירותים נלווים.
הגישה מוגבלת **לאדמין בלבד** (משתמש `admin` או תפקיד `אדמין`). מנהלים ועובדים לא רואים את הקישור ולא מקבלים את הנתונים מהשרת.

הנתונים יובאו מקובץ האקסל `סיסמאות רשתות.xlsx` כרשומות מסודרות לפי לקוח ורשת, עם אפשרות להוסיף / לערוך / למחוק בהמשך.

## נתיבים

| נתיב | תיאור | הרשאה |
|---|---|---|
| `/app/admin/passwords` | עמוד הריכוז | אדמין בלבד |
| `GET /api/admin/network_passwords` | רשימת רשומות | אדמין בלבד |
| `POST /api/admin/network_passwords` | הוספת רשומה | אדמין בלבד |
| `POST /api/admin/network_passwords/<id>` | עדכון רשומה | אדמין בלבד |
| `POST /api/admin/network_passwords/<id>/delete` | מחיקת רשומה | אדמין בלבד |

## מודל רשומה

```json
{
  "id": "uuid",
  "client": "שם לקוח / חשבון",
  "platform": "אינסטגרם | טיקטוק | ...",
  "username": "יוזר או מייל",
  "password": "סיסמה",
  "url": "קישור אופציונלי",
  "notes": "הערות",
  "created_at": "iso",
  "updated_at": "iso",
  "updated_by": "user_id"
}
```

## אחסון

- **פיתוח (JSON):** `network_passwords.json`
- **פרודקשן (PostgreSQL):** טבלה `network_passwords` עם `id` + `data` (JSONB). הטבלה נוצרת בעצלתיים בשימוש הראשון, ואם היא ריקה מיובא ה-seed מקובץ ה-JSON.

## ממשק

- קישור בסרגל הצד תחת פריטי אדמין: **סיסמאות רשתות**
- חיפוש חופשי + סינון לפי לקוח / רשת
- כרטיסים מקובצים לפי לקוח
- סיסמאות מוסתרות כברירת מחדל, עם הצגה והעתקה ללוח
- טופס הוספה/עריכה ומחיקה עם אישור

## אבטחה

הבדיקה נעשית **בשרת** (`is_strict_admin`) ולא רק ב-UI. משתמש שאינו אדמין מקבל `403`.
ההרשאה לדף רשומה גם ב-`permissions_db.json` כ-`אדמין`.

אין להפיץ את קובץ `network_passwords.json` מחוץ למערכת.
