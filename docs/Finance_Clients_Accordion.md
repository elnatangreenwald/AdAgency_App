# אקורדיון לקוחות נוספים - דף כספים

## תיאור הפיצ'ר

טבלת הלקוחות בדף הכספים מחולקת לשני חלקים:

1. **לקוחות עם חיובים פתוחים** - מוצגים קודם, ללא צורך בלחיצה
2. **לקוחות נוספים** - לקוחות שאין להם חיובים פתוחים כרגע, מוסתרים תחת אקורדיון

## לוגיקה

### חלוקת הלקוחות

```typescript
// לקוחות עם חיובים פתוחים (כולל ריטיינרים שלא שולמו)
const clientsWithOpenCharges = filteredClients.filter(c => c.filtered_open_charges > 0);

// לקוחות ללא חיובים פתוחים
const otherClients = filteredClients.filter(c => c.filtered_open_charges <= 0);
```

השדה `filtered_open_charges` כולל:
- חיובים נוספים שלא סומנו כשולמו
- ריטיינרים שלא שולמו (בחודש הנבחר או מתחילת השנה ב"כל החודשים")

### פתיחה אוטומטית בחיפוש

כשהמשתמש מקליד בתיבת החיפוש, האקורדיון נפתח אוטומטית כדי שלקוחות ללא חיובים פתוחים יופיעו בתוצאות:

```typescript
const otherClientsVisible = showOtherClients || searchTerm.trim() !== '';
```

## State

```typescript
const [showOtherClients, setShowOtherClients] = useState(false);
```

## התנהגות

| מצב | לקוחות עם חיובים פתוחים | לקוחות נוספים |
|-----|------------------------|---------------|
| ברירת מחדל | מוצגים | מוסתרים באקורדיון |
| אקורדיון פתוח | מוצגים | מוצגים |
| בזמן חיפוש | מוצגים (אם תואמים) | מוצגים (אם תואמים) |
| סינון לפי חודש | לפי חיובים בחודש | לפי חיובים בחודש |

## הערות

- הסיכומים בראש העמוד (`total_open_charges`, `total_monthly_revenue`) עדיין מתבססים על כל הלקוחות
- יצוא לאקסל כולל את כל הלקוחות
- הארכיון (חיובים ששולמו) לא מושפע מהשינוי
