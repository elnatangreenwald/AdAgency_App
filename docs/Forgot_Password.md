# שכחתי סיסמה

משתמשים יכולים לאפס סיסמה בעצמם ממסך ההתחברות. נשלח קישור למייל הרשום בפרופיל, בתוקף ל-24 שעות.

## איך זה עובד

1. במסך ההתחברות לוחצים **שכחתי סיסמה** ומזינים שם משתמש או אימייל.
2. אם נמצא משתמש עם מייל רשום, נשלח אליו קישור.
3. הלחיצה על הקישור פותחת `/app/reset-password/<token>`.
4. אחרי בחירת סיסמה חדשה חוזרים למסך ההתחברות.

ההודעה אחרי הבקשה היא כללית בכוונה, כדי לא לחשוף אם המשתמש קיים.

## תנאים

- למשתמש חייב להיות **מייל** בפרופיל (ניהול צוות).
- בשרת חייבים להיות מוגדרים:
  ```
  SMTP_SERVER=smtp.gmail.com
  SMTP_PORT=587
  SMTP_USERNAME=...
  SMTP_PASSWORD=...
  ```
- מומלץ גם `PUBLIC_APP_URL` (למשל `https://your-app.up.railway.app`) כדי שהקישור במייל יצביע לכתובת הנכונה. אם לא מוגדר, נלקח ה-host של הבקשה.

בלי SMTP או בלי מייל רשום, המשתמש צריך לפנות לאדמין — שאפשר לו לאפס סיסמה מ**ניהול צוות**.

## API

| נתיב | תיאור |
|---|---|
| `POST /reset_password_request` | בקשת קישור. גוף: `{ "username": "..." }` |
| `GET /api/reset_password/<token>` | בדיקה שהקישור תקף |
| `POST /reset_password/<token>` | עדכון סיסמה. גוף: `{ "password", "confirm_password" }` |
| `GET /reset_password/<token>` | הפניה לדף React |

## אחסון הטוקן

הטוקן נשמר על רשומת המשתמש (`reset_token`, `reset_token_expires`) ונמחק אחרי שימוש או פקיעה. בפרודקשן זה נשמר ב-PostgreSQL, בפיתוח ב-`users_db.json`.
